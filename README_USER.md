# arre食谱推荐小助手 使用说明

> 一款温馨的每日菜单推荐与食谱管理应用，告别"今天吃什么"的纠结。

## 快速开始

1. 打开 `https://cook.arrebyte.top`，或进入微信小程序「arre食谱推荐小助手」。
2. 阅读协议和隐私说明后，使用邮箱验证码、已有密码或已绑定的微信登录。
3. 从首页选菜；从「我的 → 我的私房菜」查看、创建自己的食谱。
4. 管理员可从「我的」进入后台，普通用户管理自己的内容。

本地安装和服务端运行方式见 [开发指南](README_DEV.md)。

## 功能介绍

### 智能推荐

- **午餐/晚餐推荐** — 按口味画像（常吃口味、菜系、收藏、喜恶、距上次食用天数）打分推荐，自动排除近期重复，并给出推荐理由
- **心情推荐** — 选择当前心情（开心、疲惫、想偷懒、想吃辣、想养生），获得匹配菜品
- **AI 饮食助手** — 查看口味画像，按餐段/心情/口味/耗时/食材/忌口精确推荐；也可以对话找菜、查做法、安排菜单
- **转盘抽奖** — 美食转盘随机选菜
- **收藏加权** — 收藏的菜品推荐权重更高

对话只处理食谱和日常饮食问题，发送后会先检查内容再显示回复。每账号每日最多 20 次，Web 与小程序共用，北京时间 00:00 重置；每条已受理的提问计 1 次，停止生成或删除对话不会恢复次数。管理员可调低或暂停服务，并设置全站总额度；当前状态以对话页为准。达到上限后仍可使用菜谱浏览和选菜工具。

### 明天吃什么

- 偏好过滤：快速/清淡/辣/收藏/均衡
- 设置目标道数，一键生成明日菜单
- 支持换菜、替换单道

### 食谱管理

- 菜单收录南方菜系 100 道（川菜、湘菜、贵州菜、云南菜、粤菜），以辣味为主
- 菜品信息：名称、图片/多图、视频链接（当前支持抖音和哔哩哔哩跳转播放）、分类、口味
- 详细做法：食材、调料、步骤（支持计时）、烹饪时间、难度等级
- 烹饪模式：步骤引导，计时提醒
- 私房菜入口展示本人创建、当前仍有权访问的个人和家庭菜谱，家庭菜谱带共享标记。
- 编辑页粘贴 B 站 / 抖音视频后，可点击「从视频提炼」自动填入空白的菜名、食材、用量与步骤；无法读取时可粘贴字幕。已有内容保留，核对后点击保存；无字幕视频的语音转写需管理员单独配置。
- 编辑时自动保存草稿，离开或中断后可在同一设备、同一账号恢复；保存成功后清除草稿，失败时保留
- 草稿不跨设备同步，清除浏览器/微信缓存会删除本地草稿
- 有权限的菜谱可启用/禁用、克隆、排序

### 周计划 & 购物清单

- 一键生成本周午餐/晚餐菜单
- 购物清单自动汇总食材，按蔬菜/肉类/配料/其他分类
- 支持勾选与库存标记

### 记录与回顾

- 用餐记录：记录每餐吃了什么，评分与备注
- 照片墙：时间线展示美食照片与心情
- 历史回顾：查看过往用餐记录

### 成就系统

- 80+ 成就自动解锁（初入厨房、连续七天、百菜斩、粤菜大师等）
- 按用餐/心情/推荐/照片/收藏/购物等维度自动检测
- 支持管理后台手动解锁

### 管理后台

- 仪表盘：菜品数、记录数、分类分布、热门菜品、周趋势
- 菜品 CRUD：搜索、筛选、分页、批量操作、多图上传
- 语录管理、成就管理、记录管理
- 系统设置：重复天数、每日菜品数、分类、口味、应用名称、AI 助手每账号每日请求上限及全站额度

### 开放给智能体

- 在「我的 → AI 连接」创建个人 Agent 令牌，可设置只读、顾问或完全代理权限和有效期
- Agent 通过 MCP、OpenAI 函数调用或 OpenAPI 接口访问；每个令牌只读取或修改签发者自己的数据
- 可查看调用记录并随时撤销令牌；顾问模式只推送建议，由用户决定是否采纳

## 个人信息与站内信

- 在「我的」点击头像可更换图片，点击头像旁资料区域进入个人信息设置，点击昵称可修改；账号与安全页同步展示最新资料。
- 站内信点击后直接展示详情。系统更新使用 `vX.Y.Z` 版本号和容易理解的更新说明。
- 「一周菜单与买菜清单」集中处理计划与采购；个人设置统一从「我的」进入。
- 登录页和「我的 → 关于我们」提供食谱站特色、四步使用指南、常见问题和协议，即使尚未登录也可阅读。

## 常见问题

**Q: 忘记密码怎么办？**

A: 使用绑定邮箱的验证码登录。登录后可在「我的 → 账号与安全」设置密码；更改 `ADMIN_PASSWORD` 环境变量不会重置已经创建的账号。

**Q: 数据存在哪里？**

A: 线上账号与业务数据保存在 MySQL，上传图片保存在 Garage 对象存储。个人可在「我的 → 账号与安全」导出自己的数据。部署者备份时还需包括图片和必要配置；本地 SQLite 的 WAL 模式应使用在线备份或停服务后完整备份，不能只复制一个正在写入的 `.db` 文件。详见 [部署指南](docs/deployment.md)。

**Q: 如何修改端口？**

A: `.env` 中设置 `PORT=新端口号`，重启生效。

**Q: 手机可以用吗？**

A: 支持原生微信小程序、手机浏览器和 PWA 添加到主屏幕。

**Q: 小程序选图或上传失败，要在哪里打开？**

A: 图片上传无需业务域名。部署者需在微信公众平台配置 `https://cook.arrebyte.top` 的 request 和 uploadFile 合法域名，并完善拍照/选图用途的隐私说明；用户在微信和手机系统中允许本次相机或相册操作。详见 [小程序指南](docs/miniprogram.md)。
