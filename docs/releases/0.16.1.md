# 0.16.1 iOS 小程序健康饮食控件窄屏修复

## 修复

- 健康报告的日期格、操作按钮和选择器显式约束原生控件宽度与盒模型；320px 窄屏使用单列操作区，较宽手机使用受控双列。
- 档案和文字记餐组件约束 `picker` 外层及按钮宽度，保留主次按钮状态与长文字换行，防止 iOS 默认按钮尺寸撑开卡片。
- 报告中的证据标题、长来源和餐次操作允许收缩、换行，卡片内按钮不再依赖内容宽度决定布局。
