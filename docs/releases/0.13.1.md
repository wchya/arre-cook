# 0.13.1 iOS 换肤选中样式

## 修复

用户在 iOS 微信小程序反馈选中边框过大。原配色选项把 4 rpx 边框画在整个原生按钮上，未显式约束按钮宽度，且基础重置依赖组件内的标签选择器；默认按钮尺寸与内边距可能撑大选中区域。

本次使用明确的组件类选择器覆盖原生按钮默认尺寸、内边距和伪元素描边。配色选项按四列等宽排列，选中标记改为缩略图内侧 2 rpx 细线及右上角 30 rpx 小勾选，名称不再包在选中框里。显示模式按三列等宽分配并保留至少 44 px 点击高度；主题存储和业务逻辑不变。
