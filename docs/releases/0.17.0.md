# 0.17.0 每日菜谱推荐与 Agent 计划协议

首页、明日与一周菜单、推荐官、盲盒及转盘候选、站内助手和第三方 MCP/REST 统一使用 `personal-meal-v2` 推荐引擎。内部六维评分结合个人喜好、当前需求、近期重复、做饭便利、整餐搭配和资料质量；用户界面只展示理由。

## 变化

- 收藏、真实吃后评价和明确喜恶以平滑及45天衰减学习；新增个人菜品亲和投影，可由原始数据重算。换一个只跳过，今天不想吃短期冷却，长期不喜欢可撤销。
- 统一过敏、忌口和排除条件；覆盖预置分类及常见原料别名，区分过敏分类与真实原料身份，未知耗时不通过明确时长限制。
- 同日餐次推荐快照跨来源复用，并发首次生成收敛；连续换菜累计避开已看/跳过菜，旧快照30天清理。
- 选中菜加入独立菜单和买菜清单，实际吃过后再记餐。明日整餐原子替换，周菜单保留确认计划。未来旧写入接口兼容转计划，不再新增未来实际记录。
- 第三方协议升级2.1，保留推荐字段，新增推荐/会话ID、真实曝光反馈、查询/加入/替换/撤销计划；MCP、Function Calling和OpenAPI由同一注册表生成，权限按令牌用户隔离。
- 修正推荐官长页面滚动，反馈按钮可在小屏完整访问。

规则详见 [每日菜谱推荐](../recommendations.md)，第三方集成见 [Agent API](../agent-api.md)。
