# 小程序提审说明

## 审核员登录

小程序登录页支持两种完整流程：

1. 邮箱验证码登录：输入 QQ/Foxmail 邮箱并获取验证码。
2. 账号密码登录：点击“已有密码？使用账号密码登录”，输入提审备注中提供的审核账号。

提审备注请填写真实可用的临时账号和密码，账号由部署人员根据线上环境创建，示例格式如下（提交前替换尖括号内容）：

```text
体验账号：<review-account>
体验密码：<review-password>
登录路径：打开小程序 → 勾选《用户服务协议》和《隐私政策》 → 已有密码？使用账号密码登录
```

审核账号至少准备一条菜谱、一条用餐记录和一个 Agent 连接令牌，便于审核员进入首页、饮食记录、家庭、AI 助手和 AI 连接页面。不要在仓库、截图或公开文档中提交真实密码。

## 隐私授权

登录页在任何邮箱、密码或微信登录请求前要求勾选协议；首次同意时触发微信隐私授权弹窗。协议页面明确列出邮箱、微信绑定标识、饮食记录、图片、AI 请求和 Agent 审计信息的收集目的、存储方式、数据隔离、第三方处理、保存期限和删除权利。

提审前还需在微信公众平台完成隐私保护指引配置，并将 `https://cook.arrebyte.top` 配置为业务域名和 request 合法域名。
